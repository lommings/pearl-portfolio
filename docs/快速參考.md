# 快速參考指南

## 🚀 日常更新（最常用）

### 推送更新到網站
```bash
git add .
git commit -m "更新說明"
git push
```
**等 1-2 分鐘，網站自動更新！**

### 本地預覽
```bash
npm run dev
# 開啟 http://localhost:4321
```

## 📝 撰寫文章

### 文章位置
```

```

```markdown

title: "文章標題"
description: "文章摘要"

category: "分類名稱"
tags: ["標籤1", "標籤2"]

文章內容...
```

## 🛠️ Git 常用指令

| 指令 | 說明 |
|------|------|
| `git status` | 查看狀態 |
| `git add .` | 加入所有變更 |
| `git commit -m "訊息"` | 提交變更 |
| `git push` | 推送到 GitHub |
| `git pull` | 拉取遠端變更 |
| `git log --oneline` | 查看提交歷史 |

## 📊 查看部署狀態

### GitHub
- ✅ 綠色勾勾 = 部署成功
- 🔄 黃色圓圈 = 正在部署
- ❌ 紅色叉叉 = 部署失敗

### Cloudflare Dashboard
1. https://dash.cloudflare.com
2. Workers & Pages → `pearl-portfolio`
3. Deployments 標籤

## 🐛 常見問題

### 部署失敗
1. 查看 Cloudflare 建置日誌
2. 本地執行 `npm run build` 測試
3. 修正錯誤後重新推送

### 圖片不顯示
- 確認路徑正確：`../../assets/圖片名.jpg`
- 確認檔案存在

### 變更沒更新
- 清除瀏覽器快取：`Ctrl + F5`
- 等待 1-2 分鐘讓 Cloudflare 部署完成
