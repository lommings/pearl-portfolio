## 🌐 自訂網域（可選）

### 方式 A：網域在 Cloudflare

1. Cloudflare Dashboard → Pages 專案
2. Custom domains → Set up a custom domain
3. 輸入網域
4. Activate domain
5. 完成！（自動設定 DNS）

### 方式 B：網域在其他註冊商

需要先將 DNS 轉移到 Cloudflare：

1. **在 Cloudflare 新增網站**
   - Dashboard → Add a Site → 輸入網域

2. **取得 Cloudflare Nameservers**
   - 例如：`adam.ns.cloudflare.com`
   - 例如：`bella.ns.cloudflare.com`

3. **到原註冊商更改 Nameservers**
   - 登入原註冊商
   - 找到 DNS/Nameserver 設定
   - 改為 Cloudflare 的 nameservers

4. **等待 DNS 傳播**
   - 通常 24-48 小時
   - 可用 https://dnschecker.org 檢查

5. **設定自訂網域**
   - 同方式 A 的步驟

## 🛠️ 部署失敗排解

### 常見原因
1. Markdown frontmatter 格式錯誤
2. 圖片路徑不存在
3. 組件語法錯誤

### 解決步驟
1. 查看 Cloudflare 建置日誌
2. 本地執行 `npm run build` 測試
3. 修正錯誤後重新推送
