## 📁 專案結構

```
pearl-portfolio/
├── src/
│   ├── assets/              ← 圖片資源
│   ├── components/          ← 組件
│   ├── content/blog/        ← 文章
│   ├── layouts/             ← 版型
│   └── pages/               ← 頁面
├── scripts/                 ← 工具腳本
│   ├── generate-novel.mjs   ← 小說生成
│   └── extract-images.mjs   ← 圖片提取
├── 小說原稿/                 ← Word 原稿
├── public/                  ← 靜態資源
└── docs/                    ← 本文檔
```
