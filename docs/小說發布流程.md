# 小說發布流程

## 概述

將一個包含多章節的 Word 檔案，自動分割成多篇部落格文章發布。

## 發布指令

```
發布小說，路徑：C:\Users\lommi\Projects\pearl-portfolio\download_pic\小說名.docx
```

## Word 檔案格式要求

### 章節標題格式
```
[Chapter 1]
第一章的內容...

[Chapter 2]
第二章的內容...
```

### 圖片
- 圖片會自動跟隨所屬章節
- 建議圖片放在章節內容中間或結尾

## 發布流程

1. 使用者提供 Word 檔案路徑
2. 詢問分類和標籤
3. 讀取 Word 檔案內容
4. 按 `[Chapter X]` 分割章節
5. 檢查是否已有同名小說的文章
   - 如有，詢問是否覆蓋
   - 如新版章節較少，刪除多餘章節
6. 生成文章：
   - 目錄頁：`小說名-目錄.md`
   - 各章節：`小說名-第01章.md`, `小說名-第02章.md`...
7. 推送到 GitHub

## 文章規格

| 項目 | 設定 |
|------|------|
| **檔名格式** | `小說名-第XX章.md` |
| **標題格式** | `小說名-第XX章` |
| **日期** | 首次發布日，每章間隔 1 分鐘（排序用） |
| **描述** | 自動擷取開頭 50-100 字 |
| **導航** | 上一章/下一章 + 回到目錄（使用 ChapterNav 組件） |

## 更新規則

- **新版章節更多**：新增章節
- **新版章節更少**：刪除多餘章節
- **日期保持不變**：維持原始發布日期

## ChapterNav 組件使用

在章節文章的 MDX 中使用：

```mdx
import ChapterNav from '../../components/ChapterNav.astro';

（文章內容）

<ChapterNav
  prevChapter={{ title: "第01章", url: "/blog/小說名-第01章/" }}
  nextChapter={{ title: "第03章", url: "/blog/小說名-第03章/" }}
  indexPage={{ title: "目錄", url: "/blog/小說名-目錄/" }}
/>
```
