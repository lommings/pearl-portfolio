# 小說發布流程

## 快速指令

跟 AI 說：
> 「幫我把 `[相二]直線與迷宮.docx` 發布到網站」

或更新時：
> 「Word 檔更新了，幫我重新部署《直線與迷宮》」

---

## Word 檔案格式要求

```
Summary:
這裡放小說簡介，會顯示在目錄頁「故事介紹」區塊。
可以多行。

Chapter 01-第一章標題
第一章內文...
可以用斜體、粗體、插入圖片。

Chapter 02-第二章標題
第二章內文...

Chapter 13-最後一章(完結)
最後一章內文...

Chapter 14-番外標題(番外)
番外內文...
```

### 格式重點
- **Summary:** 放最前面（冒號後換行）
- **章節格式:** `Chapter XX-章節名稱`（XX 是數字，用半形減號 `-` 連接）
- **格式保留:** 斜體、粗體、圖片都會轉換到網頁
- **完結/番外:** 可在標題加 `(完結)` 或 `(番外)`

---

## 腳本用法（進階）

```bash
node scripts/generate-novel.mjs <Word檔案> <英文網址> <分類名稱> <標籤>
```

### 參數說明

| 參數 | 說明 | 範例 |
|------|------|------|
| Word檔案 | 放在 `小說原稿/` 資料夾 | `小說原稿/[相二]直線與迷宮.docx` |
| 英文網址 | 網址用的英文名稱 | `straight-line-and-maze` |
| 分類名稱 | 側邊欄的分類 | `[相二]直線與迷宮` |
| 標籤 | 用逗號分隔 | `相葉雅紀,二宮和也` |

### 完整範例

```bash
node scripts/generate-novel.mjs "小說原稿/[相二]直線與迷宮.docx" "straight-line-and-maze" "[相二]直線與迷宮" "相葉雅紀,二宮和也"
```

## 顯示格式

### 目錄頁
```
## 📖 故事介紹
（Summary 內容）

## 📚 章節目錄
1. 第01章-完美的球體
2. 第02章-水底暈開的墨
...
```

### 章節標題（最新文章列表）
完整格式，包含小說名稱：
```
[相二]直線與迷宮 第01章-完美的球體
```

### 側邊欄分類列表
簡潔格式，只顯示章節：
```
第01章-完美的球體
第02章-水底暈開的墨
```

### 最新文章
- 顯示 3 篇
- 按發布時間排序（最新在前）

---

## 日期邏輯

- 發布時全部章節使用當下時間
- 每章間隔 1 分鐘（ch01, ch02, ch03...）
- 最後一章時間最新，會顯示在「最新文章」最上面
