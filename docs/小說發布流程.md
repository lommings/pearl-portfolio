# 小說發布流程

## 概述

將一個包含多章節的 Word 檔案，自動分割成多篇部落格文章發布。

## 快速開始

### 1. 存放 Word 檔案
```
C:\Users\lommi\Projects\pearl-portfolio\小說原稿\你的小說.docx
```

### 2. 發布指令
跟 AI 說：
```
發布小說，路徑：C:\Users\lommi\Projects\pearl-portfolio\小說原稿\你的小說.docx
```

### 3. 回答問題
- **分類**：例如「小說創作」或小說名稱
- **標籤**：用逗號分隔，例如「二宮和也, 大野智, 相葉雅紀」

---

## Word 檔案格式要求

### 章節標題格式
使用 `Chapter XX` 格式標記章節（XX 為數字）：

```
Chapter 01
第一章的內容...

Chapter 02
第二章的內容...

Chapter 03
第三章的內容...
```

### 圖片
- 直接在 Word 中插入圖片
- 圖片會自動提取並放入對應章節
- 支援 JPEG、PNG 等常見格式

---

## 發布流程（AI 自動執行）

1. **讀取 Word 檔案**
   - 使用 mammoth 套件解析 .docx
   - 提取文字內容和圖片

2. **詢問分類和標籤**
   - 分類：每本小說可以有自己的分類
   - 標籤：所有章節共用相同標籤

3. **分割章節**
   - 按 `Chapter XX` 標記分割
   - 每章自動生成描述（取開頭 80 字）

4. **生成文章檔案**
   - 目錄頁：`小說名-目錄.md`
   - 各章節：`小說名-第01章.md`, `小說名-第02章.md`...

5. **處理圖片**
   - 提取到 `src/assets/小說名/` 資料夾
   - 自動插入到對應章節

6. **推送到 GitHub**
   - Cloudflare Pages 自動部署
   - 約 1-3 分鐘後上線

---

## 文章規格

| 項目 | 設定 |
|------|------|
| **檔名格式** | `小說名-第XX章.md`（去除方括號） |
| **標題格式** | `小說名-第XX章` |
| **日期** | 發布當天，每章間隔 1 分鐘（用於排序） |
| **描述** | 自動擷取開頭約 80 字 |
| **導航** | 每章底部有「上一章 / 目錄 / 下一章」連結 |

---

## 更新已發布的小說

### 修改內容後重新發布
1. 修改 Word 檔案
2. 用相同指令重新發布
3. AI 會詢問是否覆蓋

### 更新規則
| 情況 | 處理方式 |
|------|----------|
| 新版章節更多 | 新增章節 |
| 新版章節更少 | 刪除多餘章節 |
| 更新後日期 | 保持原始發布日期不變 |

### 修改標籤
跟 AI 說：
```
這篇小說的標籤要改成：標籤1, 標籤2, 標籤3
```

## 常見問題

### Q: 圖片沒有顯示？
A: 確認 Word 中的圖片是直接插入的，不是連結。AI 會自動提取並上傳。

### Q: 章節順序不對？
A: 確認 Word 中的章節標題是 `Chapter 01`, `Chapter 02` 格式，數字要連續。

### Q: 想修改某一章的內容？
A: 直接編輯 `src/content/blog/` 裡的 .md 檔案，然後推送到 GitHub。

### Q: 想刪除整本小說？
A: 刪除以下檔案後推送：
- `src/content/blog/小說名-*.md`（所有章節和目錄）
- `src/assets/小說名/`（圖片資料夾）
