# 網站功能說明

## 📂 分類與標籤

### 使用方式

在文章 frontmatter 中加入：

```markdown
---
title: '文章標題'
description: '文章描述'
pubDate: 'Jul 16 2026'
category: '小說創作'           # 分類（只能一個）
tags: ['標籤1', '標籤2']       # 標籤（可以多個）
---
```

### 分類規則

| 類型 | 說明 |
|------|------|
| **分類** | 每篇文章只能有一個，用於左側選單分組 |
| **標籤** | 可以有多個，用於關鍵字標記 |

### 建議分類
- 故事類：`小說創作`、`短篇故事`、`連載小說`
- 遊戲類：`RPG遊戲`、`解謎遊戲`
- 其他：`教學`、`日記`、`公告`

## 📊 網站統計

### Cloudflare Analytics（整體數據）

**查看方式：**
1. 登入 https://dash.cloudflare.com
2. Workers & Pages → `pearl-portfolio`
3. Analytics 標籤

**可以看到：**
- 每日/每週/每月訪客數
- 總頁面瀏覽量
- 流量來源
- 訪客國家/地區
- 瀏覽器/裝置類型

### Waline Pageview（文章瀏覽數）

- 每篇文章標題下方顯示「👁️ X 次瀏覽」
- 後台管理：你的 Waline 網址 `/ui`

## 🖼️ 網站圖示（Favicon）

瀏覽器頁籤上的小圖示。

### 檔案位置
```
public/
├── favicon.ico    ← 主要圖示（瀏覽器用）
└── favicon.png    ← PNG 版本（Apple 裝置用）
```

### 更換方式
1. 準備正方形圖片（建議 512x512 px）
2. 轉換工具：https://favicon.io
3. 把產生的檔案放到 `public/` 取代原本的

### 相關程式碼
`src/components/BaseHead.astro`：
```html
<link rel="icon" type="image/png" href="/favicon.png" />
<link rel="icon" href="/favicon.ico" />
<link rel="apple-touch-icon" href="/favicon.png" />
```

## 🔤 標題字級階層

內容區（`.prose`）的標題字級經過調整，建立清晰的視覺層次：

| 元素 | 字級 | 用途 |
|------|------|------|
| 頁面標題 (h1) | 1.8rem ≈ 29px | 文章主標題 |
| 內容 h2 | 1.35em ≈ 27px | 章節大標（如「故事介紹」「章節目錄」） |
| 內容 h3 | 1.2em ≈ 24px | 子章節 |
| 內容 h4 | 1.1em ≈ 22px | 細節標題 |
| 內文 | 20px | 一般段落 |

### 樣式位置
```
src/styles/global.css
```

### 相關程式碼
```css
/* 內容區標題階層縮小 */
.prose h2 { font-size: 1.35em; }
.prose h3 { font-size: 1.2em; }
.prose h4 { font-size: 1.1em; }
.prose h5 { font-size: 1.05em; }
```
